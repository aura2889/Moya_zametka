# Моя заметка

PWA-приложение: личная библиотека заметок со вкладками.

- **Тілектер** — тосты и пожелания (той, туған күн, шілдехана, қаза, мерекелер…)
- **Даналық** — мудрые и смешные слова (мотивация, философия, нақыл, юмор…)
- **Өмір** 🔒 — личные записи (цели, хронология, дневник, финансы, семья). Зашифровано AES-GCM в `private.enc.js`, открывается кодом доступа
- ✦ «Мысль дня» при каждом открытии
- ⭐ **Таңдаулы** — избранное, поиск по всем заметкам, 🎲 случайная заметка

## Как добавлять заметки
Все данные в `data.js`: раздел → подвкладка → `items` с полями `w` (заголовок), `t` (текст), `l` (язык, необязательно).

## Установка
Android: Chrome → «Добавить на главный экран». iOS: Safari → Поделиться → «На экран Домой».
